🌍 Traveloop - Smart Travel Planning Platform
Traveloop is an  travel itinerary planner developed for the Odoo Hackathon 2026. It helps users plan their trips with a seamless experience, managing everything from activity timelines to backend data persistence.

🛠️ Tech Stack
Backend: Java Spring Boot, Spring Data JPA, Maven

Frontend: HTML5, CSS3 (3D Enhancements), Vanilla JavaScript, Axios

Database: MySQL

Tools: Cursor AI, IntelliJ IDEA, Git

✨ Key Features
Dynamic Itinerary Management: Create, update, and manage travel plans in real-time.

Full-Stack Integration: Seamless communication between the JavaScript frontend and Java Spring Boot backend.

Data Persistence: All trip details are securely stored in a MySQL database.

Modern UI: Responsive design with 3D visual guide testing and smooth transitions.

🏗️ Project Architecture
The project follows a RESTful architecture:

Frontend: Handles user interaction and state management using Axios for API calls.

Backend: A Spring Boot application providing robust REST endpoints.

Database: MySQL handles relational data storage for all itineraries.

💻 Technical Implementation (Inside the Code)
Persistence: Implemented JPA repositories for automatic entity mapping to MySQL.

Connectivity: Used CORS configuration to bridge the frontend-backend communication.

Automation: Built using Maven for efficient dependency management and builds.

🛠️ How to Run Locally
Clone the repository: git clone https://github.com/haswinsk/traveloop.git

Configure MySQL in src/main/resources/application.properties.

Run the Spring Boot application using ./mvnw spring-boot:run.

Open index.html in your browser.
