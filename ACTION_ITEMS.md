## 🎨 WHAT YOU CAN CUSTOMIZE

### Tilt Sensitivity (Edit main.html)
```javascript
max: 15,    // Change this for more/less tilt
scale: 1.02, // Change for more/less zoom
speed: 400,  // Change for faster/slower animation
```

### Blur Intensity (Edit styles.css)
```css
backdrop-filter: blur(10px); /* Change to 5, 8, 12, 15, etc. */
```

### Animation Speed (Edit styles.css)
```css
animation: float-icon-1 4s ease-in-out infinite;
/* Change "4s" to "3s" (faster) or "5s" (slower) */
```

## 📞 SUPPORT & TROUBLESHOOTING

### Issue: Cards not tilting
**Solution**: Check browser console for errors, verify Vanilla Tilt loaded

### Issue: Animations too slow/fast
**Solution**: Edit speed values in main.html and styles.css

### Issue: Performance problems
**Solution**: Reduce blur/tilt values or close other browser tabs

### Issue: Doesn't work on mobile
**Solution**: Effects are optimized for mobile, check if JavaScript enabled
