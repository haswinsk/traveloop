## 🎨 CUSTOMIZATION

### Adjust 3D Intensity
Edit `main.html` line ~434:
```javascript
max: 15,        // 1-30 for more/less tilt
scale: 1.02,    // 1.0-1.1 for zoom
speed: 400,     // 100-800 for animation speed
```

### Adjust Blur Effect
Edit `styles.css`:
```css
backdrop-filter: blur(10px); /* Change 10 to 5-20 */
```

### Adjust Animation Speed
Edit `styles.css`:
```css
animation: float-icon-1 4s ease-in-out infinite;
/* Change "4s" to custom duration */
```
